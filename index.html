How It Works

01 — Code: Developer pushes changes to GitHub.

02 — Build: Azure Pipelines automatically builds the application.

03 — Containerize: Docker packages the application into a container image.

04 — Deploy: The image is stored in Azure Container Registry and deployed to Azure App Service.
